# PRACH 기회 중재 — 천장 밀착 지속성 개선

2026-10-22. 6 UE, lockstep 1슬롯, `RSS_RO_ARBITRATE=1`, 120초.
격리된 자체 AWS 테스트베드(ZMQ 가상 RF, 외부망 없음). **gNB 무수정.**

## 무엇을 바꿨나

OAI UE의 `nr_ue_prach_scheduler()`에서 PRACH PDU 할당 직전에
`(frame, slot)` 기회를 프로세스 전역 뮤텍스로 선착순 점유한다.
한 기회에 UE 인스턴스 1개만 프리앰블을 전송하고, 나머지는 다음 기회로 밀린다.

라디오 쓰기 타임스탬프는 건드리지 않는다 — 6 인스턴스가 하나의 ZMQ 스트림을
공유해 신호가 합산되므로 같은 타임스탬프여야 하고, 쓰기 시각을 흩뜨리는 방식
(`RSS_PHASE_STAGGER`)은 `nr-ue-ru.c`의 late-drop 가드와 충돌해 이미 반증됐다.

패치: 세션 스크래치패드 `ro-arbitration.patch` (537줄, 추가 285줄).
노브 `RSS_RO_ARBITRATE` (0 = 상류 동작). `RSS_RO_COOLDOWN`·`RSS_RO_RR`도 들어
있으나 **둘 다 실측 무효**이며 기본값 0이다.

## 왜 이것이 지표를 움직이나

거절(`Sending rrcReject`)은 **점유가 정확히 천장(96)일 때만** 발생한다
(제거 완료 기준 재구성에서 100%). 따라서 "거절 간 공백"은 "천장 아래 체류 시간"이다.

측정된 인과 사슬:

```
생성 뭉침 → (2.0초 뒤) 해제 뭉침 → 깊은 파임 → 긴 공백
   CV 2.04      교차상관 r=+0.99      r=+0.60      36 ms/슬롯
```

컨텍스트 수명이 1,999.4 ± 0.3 ms로 거의 상수이므로 해제는 생성의 정확한 메아리다.
기회 격자가 10 ms 주기·FDM 1개뿐이라 준비된 인스턴스가 한 기회에 모두 쏘고
다음 기회를 비운다(1 ms 내 동시 도착 35.3%). 필요한 기회 점유율은 45%뿐이므로
한 기회당 1개로 제한해도 처리율 손실 없이 생성이 10 ms 격자에 펴진다.

## 결과

| | 수락/s | 평균점유 | 천장체류 | 천장미달 최장 | p90 | p50 |
|---|---|---|---|---|---|---|
| 중재 없음 (기준) | 41.4 | 91.3 | 23.9% | **2,640 ms** | 370 | 72 |
| 중재 ON (60초, 5런) | 42.2~42.6 | 92.9~93.5 | 23.1~28.4% | **621~1,018 ms** | 232~283 | 76~100 |
| 중재 ON (120초, 본 런) | 42.5 | 93.4 | 27.8% | **1,018 ms** | 232 | 85 |

**p90 370 → 232~283 ms**가 가장 신뢰할 수 있는 개선이다.
최장값은 구간 수에 따라 커지는 불안정한 통계다(60초 ~400구간 → 120초 852구간).

## 목표 미달 — 그리고 왜

목표는 **최장 공백 < 100 ms**이고 달성하지 못했다.

천장 고정 조건은 `수락률 ≥ 천장 / T_slot = 96 / 2.154s =` **44.9/s**다.
이 세션에서 측정한 13개 설정의 수락률:

**41.4, 41.9, 41.9, 41.9, 42.1, 42.2, 42.2, 42.3, 42.4, 42.4, 42.4, 42.5, 42.6 /s**

변경한 것: 인스턴스 4·6·8·10, RA 깊이 1·2, lockstep 창 4종, 기회 중재 on/off,
라운드로빈 on/off, 쿨다운 0·2·4·6, 프리앰블 분할 on/off, `target_occupancy` 5종,
`honor_reject` 0·1, 거절 백오프 3종. **전부 3% 밴드 안.**

→ 평균점유가 92.9~93.9에 머물고 천장 체류가 29.3%를 넘지 못한다.
→ **UE 측 수정으로는 이 셀 설정에서 목표에 도달할 수 없다.**

구속하는 양은 전부 gNB 측이다:

| 양 | 실측 |
|---|---|
| 천장 | 96 (DU 선언 용량) |
| 컨텍스트 보유 | 1,999.4 ± 0.3 ms |
| 제거 지연 | 154.4 ± 17.6 ms (CU 비동기 2단계) |
| 수락 상한 | ~42.6/s |
| PRACH 기회 | 10 ms 주기, FDM 1개 |
| 천장 이력현상 | 천장에서 수락 1~3/s, 거절 23~37/s |
