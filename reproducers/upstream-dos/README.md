# Upstream DoS 재현 도구

상태: **범위 정의 단계.** `Upstream DoS`는 프로젝트 작업명이다. 무선 구간의 표준
방향 용어는 uplink(UL, 상향링크)이므로 기술 문서에서는 실제 채널·절차와 함께
`uplink`를 사용한다. 아직 하나의 표준 공격 절차로 확정하지 않았다.

PRACH·PUSCH·PUCCH 자원 압력, 상위 프로토콜 절차 반복, 물리 계층 간섭은 구현과
관측 지표가 서로 다르다. 다음 항목을 1차 출처와 팀 테스트베드 제약으로 확정하기
전에는 코드를 만들지 않는다.

- 공격 계층, 표준 메시지 또는 채널, 고갈시키려는 정확한 자원
- 공격자가 통제할 입력과 gNB를 수정하지 않고 가능한 실행 경로
- 정상 UE 대조군과 서비스 영향·회복의 정량 합격 기준
- ZMQ에서 검증할 범위와 차폐 OTA에서만 검증할 범위
- RRC storm과 분리된 라벨 계약, run ID, 증거 manifest

모든 실험은 팀 장비와 ZMQ 또는 RF 차폐 환경에서만 수행한다. 실행 원문은
`reproducers/upstream-dos/runs/`에 로컬 보존하며 Git에는 요약과 무결성 정보만 올린다.
